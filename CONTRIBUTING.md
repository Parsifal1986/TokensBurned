# Contributing to TokensBurned

Thanks for helping make AI coding usage more transparent without weakening developer privacy.

## Local setup

Requirements: Node.js 20 or newer and npm.

```bash
npm install
npm run plugin:sync
npm run check
```

Run the Pages site locally:

```bash
npm run dev
```

Then open `http://127.0.0.1:4173`.

## Repository layout

- `src/` contains the standalone client.
- `public/` contains the static website.
- `skills/`, `commands/`, and `hooks/` contain shared plugin components.
- `plugins/tokensburned/` is generated by `npm run plugin:sync`. Do not edit copied runtime files there directly.

## Tests

`npm run check` runs syntax checks and the complete Node test suite. Add focused tests whenever you change parsing, normalization, privacy boundaries, card composition, or install manifests.

## Plugin changes

After editing shared client or plugin sources:

```bash
npm run plugin:sync
npm run check
```

Codex development installs also require a cachebuster refresh and local reinstall. Follow the plugin development instructions in the repository tooling.

## Pull requests

- Keep new collection paths allow-list based.
- Include the precise harness/version used for integration tests.
- Do not add prompt or source-code collection.
- Document whether a compatibility claim is native, official telemetry, adapter, or fallback.
